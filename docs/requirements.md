# 콘서트 예약 서비스 요구사항 분석

API List

-------

1. 유저 토큰 발급 API 
- 해당 API 요청시 유저 토큰을 발급한다.
- 유저 토큰은 유저의 UUID와 해당 유저의 대기 순서를 포함한다.
- (제약사항) 대기 순서는 실시간으로 증감되어야 한다.

-----

2. 예약 가능 날짜 / 좌석 조회 API 
 - 유저 토큰을 이용한 대기열 검증을 통과 후 해당 API 요청이 가능하다.
 - 해당 API를 통해 예약 가능한 날짜 목록 조회 가능
 - 날짜 정보 입력 받아 예약 가능한 좌석 정보 조회 가능
 - 좌석 정보는 1~50까지의 좌석번호로 관리
 - (제약사항) 1~ 50 이외에 좌석 정보가 입력되면 에러 처리한다.


 
------

3. 좌석 예약 요청 API
 - 유저 토큰을 이용한 대기열 검증을 통과 후 해당 API 요청이 가능하다.
 - 날짜와 좌석 정보를 입력 받아 좌석 예약 처리 
 - 좌석 예약 시 요청자에게 5분간 임시 배정
 - 5분 내 결제가 완료되지 않으면 좌석 임시 배정은 해제
 - 좌석 임시 배정 상태일 때는 다른 사용자가 예약 불가능

------

4. 잔액 충전 / 조회 API
 - 유저 토큰을 이용한 대기열 검증을 통과 후 해당 API 요청이 가능
 - 사용자 식별자 및 충전 금액을 입력 받아 해당 사용자의 잔액 충전
 - 사용자 식별자를 통해 사용자 잔액 조회

-------

5. 결제 API
 - 유저 토큰을 이용한 대기열 검증을 통과 후 해당 API 요청이 가능
 - 해당 API 요청을 통해 좌석 결제를 진행한다.
 - 결제가 완료되면 좌석 소유를 유저에게 할당한다.
 - 좌석이 할당된 유저의 대기열 토큰을 만료 처리한다.
 - (제약사항) 잔액이 부족시 좌석 결제는 실패
